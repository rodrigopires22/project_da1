Computes the shortest path between two locations using Dijkstra's algorithm.

This function implements Dijkstra's algorithm to find the shortest path between a source and destination node in the graph, based on the selected mode of transportation.

Parameters
sourceThe starting location code.
destThe destination location code.
modeThe mode of transportation ("driving" or "walking").
Returns
A vector containing the codes of nodes representing the shortest path from the source to the destination. Returns an empty vector if no path exists.

The function initializes the distance map and priority queue, processes each node's adjacency list, and updates the distances accordingly. It constructs the path by backtracking from the destination to the source using the parent map.

The time complexity is O((V + E) log V), where V is the number of nodes and E is the number of edges. This arises from processing each edge and maintaining the priority queue.

Finds a route between two locations with restrictions.

This function calculates the shortest path between a source and destination while considering various restrictions such as nodes to avoid, segments to avoid, and an optional mandatory node to include in the route.

Parameters
sourceThe starting location code.
destThe destination location code.
modeThe mode of transportation ("driving" or "walking").
avoidNodesA set of nodes that should be excluded from the route.
avoidSegmentsA set of segments (pairs of nodes) that should be excluded from the route.
includeNodeAn optional node that must be included in the route.
Returns
A pair containing:
  • A vector of IDs representing the restricted route.
  • The total travel time for the route.

The function uses a helper lambda to execute a modified version of Dijkstra's algorithm with the given restrictions. If a mandatory node is specified, the route is split into two parts: one from the source to the mandatory node and another from the mandatory node to the destination. The two paths are concatenated to form the complete route.

The time complexity is O(k * (V + E) log V), where k is the number of Dijkstra calls required (typically 1 or 2), V is the number of nodes, and E is the number of edges in the graph.

Finds the best and alternative routes between two locations.

This function calculates the shortest path (best route) using Dijkstra's algorithm and attempts to find an alternative route by temporarily removing edges from the best route and re-running Dijkstra's algorithm.

Parameters
sourceThe starting location code.
destThe destination location code.
modeThe mode of transportation ("driving" or "walking").
Returns
A tuple containing:
  • A vector of IDs for the best route.
  • A vector of IDs for the alternative route (if found).
  • The total time for the best route.
  • The total time for the alternative route.

The function uses the adjacency list to remove edges temporarily and tests alternative routes. It also converts location codes to IDs and calculates the total time for each route.

The time complexity is approximately O(k * (V + E) log V), where k is the number of edges in the best route, V is the number of nodes, and E is the number of edges in the graph. This accounts for multiple calls to Dijkstra's algorithm.

void Graph::loadDistances ( const std::string & filename)

Loads distances between locations from a CSV file and updates the graph.

This function reads a CSV file containing pairs of locations along with driving and walking times. The extracted data is used to update the adjacency list of the graph with distance information.

Parameters
filenameThe name of the CSV file containing the distances to be loaded.

The function skips the first line of the file (header) and processes each subsequent line to extract data. Driving and walking times are read, and if the driving time is valid, the adjacency list of the graph is updated for both locations.

Exceptions
std::ifstream::failureIf the file cannot be opened, an error message is printed, and the function returns without modifying the graph's state.

The time complexity is O(n), where n is the number of lines in the CSV file, as each line is processed once.
